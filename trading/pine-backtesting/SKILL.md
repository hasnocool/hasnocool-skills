# Pine Backtesting

Use an external interpreter or deterministic backtesting function rather than manually simulating every bar in the model.

Capture:

- return
- drawdown
- Sharpe-like risk metrics
- trade count
- win rate
- profit factor
- parameter sensitivity
- out-of-sample performance

Never rank strategies on return alone.
