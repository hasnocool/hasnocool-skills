# Runtime Diagnostics

Inspect:

1. HASNOCOOL_SKILLS_DIR.
2. Skill discovery results.
3. Selected Skill loading.
4. Function manifest loading.
5. Async subprocess execution.
6. Structured function output.

Do not copy the entire catalog into model context while diagnosing it.
